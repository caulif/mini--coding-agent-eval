What can repeated runs of the same task tell us about a prompt's effect?

Repeats reveal variation within a task; different tasks expand coverage. They provide different evidence.

Repetition and success

A successful attempt may depend on one generated path. Repeating a task from the same starting state reveals stability under the current settings. Temperature zero does not guarantee determinism; provider implementation and operating conditions can still vary.

Two successes in three attempts describe this task's observed 2/3. Five tasks repeated three times produce fifteen attempts, but still only five tasks. Repetition mainly examines within-task variation; additional tasks extend coverage.

Three success measures

Per-attempt success describes performance in one opportunity. Any-success asks whether at least one attempt succeeded. All-success asks whether every attempt in the group succeeded. This project reports the latter two as empirical proportions of tasks.

For a task with pass, fail, pass, the observed per-attempt rate is 2/3, any-success is true, and all-success is false. The useful measure depends on how many opportunities the product provides and whether it can reliably identify a successful candidate.

Fair version comparisons

A/B uses the same tasks, model, tools, and budget, starting fresh every time. Within each task/repeat pair, randomized A/B order interleaves execution to reduce systematic time effects. The repeat identifier pairs experimental records; it does not force identical model randomness.

Per-task changes precede the aggregate B−A. Equal repeat counts here make task-averaged and trial-averaged success rates agree. Uncertainty analysis can explore sensitivity to task composition, but small samples still require cautious interpretation.

The task bootstrap used here

Compute B−A for each task, resample tasks with replacement, and average their differences. This explores sensitivity to the observed task mix without fully modeling within-task stochasticity. With only five tasks, the interval is descriptive.

Limits of the conclusion

If both versions pass every task, this test has not observed a functional gain. Even a bootstrap interval collapsing to zero cannot establish equivalent capabilities. Tasks may be easy, coverage narrow, or problems familiar from training. A next experiment can add tasks selected in advance; it cannot selectively retain only results favoring B.
